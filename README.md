🔄 Versioning

Projects follow their own versioning schemes.

Whenever possible, releases use Semantic Versioning:

MAJOR.MINOR.PATCH

MAJOR – Breaking changes.
MINOR – New features and backward-compatible improvements.
PATCH – Bug fixes and minor improvements.
